# 初期端末とエンコーディングの契約

2026-11-16 の実装分担変更：[Rust端末moduleの設計](native-terminal-core-ja-jp.md)に従い、全対応エンコーディングと入力モードを含む以下の動作をC#への切替なしで処理する。目標設計は未実装。この変更は処理の所有者を変更し、合意済みの端末動作や対象外の拡張機能は変更しない。

2026-11-10 時点の仕様。資料に基づく Q103、Q117～Q128、Q144～Q145、Q149～Q154 の選択を確定する。動作の参照先は Tera Term 5.7.1。以下の TabTty 固有の調整と既存のユーザー決定が優先する。実装済みの互換性や xterm の全機能への対応を示すものではない。

## 端末操作

7 ビットの ESC 制御形式を受け付ける。上位バイトは選択したコーデックに従い、生の C1 として一律に認識しない。デコード後の C1 スカラー値は未対応の非印字制御とする。VT コマンドとして実行しない。Raw は受信バイトをそのまま保持する。既定では原点モードはオフ、自動折り返しはオン、挿入と LNM はオフ、アプリケーションカーソルとキーパッドはオフ、通常画面、マウスとブラケットペーストはオフ、白の前景と黒の背景は固定、カーソルは表示された点滅ブロック。既定のタブ停止位置は 1 始まりの 9、17、25 列目以降。

| 系列 | 初期対応の操作 |
| --- | --- |
| C0 | NUL は無視。BEL はアプリの視覚ベル方針に従う。BS は消去せず左へ移動。HT は次の停止位置へ移動。LF/VT/FF は下へ移動し、LNM 時は復帰も行う。CR は復帰。SO/SI は該当する文字集合やカナ状態を呼び出す。CAN/SUB は未完了のエスケープをキャンセル。 |
| ESC | `7/8` はカーソル、表示属性、原点と折り返し、文字集合状態を保存または復元。`D/E/M` は IND/NEL/RI。`H` はタブ停止位置を設定。`=/ >` はアプリケーションまたは数値キーパッド。`c` は RIS。 |
| CSI カーソル | `A/B/C/D` は相対移動、`E/F` は次または前の行の 1 列目、`G` とバッククォートは HPA、`d` は VPA、`H/f` は CUP/HVP。既定の回数は 1、0 も 1 とする。適用範囲内に制限する。 |
| CSI 編集 | `@` は ICH、`P` は DCH、`X` は ECH、`L/M` は IL/DL、`J/K` は ED/EL 0/1/2、`3J` はスクロールバック消去。空白には現在の消去属性を使う。 |
| スクロール | `S/T` はカーソル行に依存せずスクロール領域全体で SU/SD。`r` は DECSTBM、上端 < 下端の場合に有効。不正なマージンは以前の状態を保つ。 |
| タブと保存 | `I/Z` は CHT/CBT、`g` は TBC で 0 は現在位置、3 はすべて。CSI `s/u` はカーソル位置だけを保存または復元する。ESC 7/8 の完全な状態とは別。 |
| モード | ANSI 4 は挿入、20 は受信側 LNM。DEC ?1 はアプリケーションカーソル、?6 は原点、?7 は自動折り返し、?25 はカーソル表示。未対応のモード項目は項目単位で無視。 |
| 画面 | ?47 は消去や保存なしで切り替え。?1047 は代替画面に入り、復帰時に代替画面を消去。?1048 は完全なカーソル状態を保存または復元。?1049 は通常画面のカーソルを保存し、消去済みの代替画面に入り、復帰時に復元。設定や解除を繰り返しても結果は同じ。 |
| 応答 | 一次 DA は `CSI ?1;2c`。DSR 5 は `CSI 0n`、CPR 6 は `CSI row;column R`、プライベート CPR ?6 はプライベート応答。任意の OSC やデバイス問い合わせには応答しない。 |
| カーソル形状 | DECSCUSR `CSI Ps SP q` は 0/1 が点滅ブロック、2 が点灯ブロック、3/4 が下線、5/6 がバー。Windows で点滅無効の場合は無効のまま。 |
| 入力モード | マウス ?9/1000/1002/1003、座標形式 ?1006、ブラケットペースト ?2004。 |
| リセット | CSI `!p` の DECSTR は表示属性、挿入、原点、LNM、マージン、カーソルとアプリケーションキーパッドのモード、保存カーソルの既定値をリセットする。テキストと履歴の消去や画面切り替えは行わない。RIS はさらに両画面と履歴を消去し、タブ停止位置、文字集合、入力モードをリセットして通常画面に戻る。 |

プライベート指定、パラメーター、中間バイト、終端バイトの組を一単位として適用する。未知のコマンドの末尾が既知の形に見えても実行しない。正しくフレーミングされた未対応制御はパーサー上限内で無視する。OSC は BEL または ST、DCS/SOS/PM/APC は ST で終端し、CAN/SUB でキャンセルする。埋め込まれた対象の C0 は一度だけ実行する。新しいシーケンスを始める ESC は、文字列の終端である場合を除き、先行する未完了シーケンスをキャンセルする。EOF で途切れた制御はテキストとして表示せず破棄する。パーサー処理が上限を超えたら明示的なリソース障害とする。

ED2 はアクティブページを履歴に送らず消去する。ED3 は履歴だけを消去し、アクティブページ、カーソル、マージンを保持する。IND は LNM でも列を維持する。LNM と RIS は、プロファイルの Enter やエンコーディングの設定、トランスポートの接続、ログ、アプリテーマを変更しない。テキスト消去は Q149 に従う。移動とリセットでログ用の LF を生成しない。DECCOLM、外側のウィンドウへのコマンド、リモートからのタイトル、アイコン、クリップボードの変更、画像、ハイパーリンクの有効化は対象外。OSC 0/1/2/8/52 は消費するが、これらの外部効果を発生させない。OSC 8 のラベルは後続の通常テキストとして扱う。OSC を終端する BEL でベルを鳴らさない。

ESC ( / ESC ) で G0/G1 に ASCII と DEC 特殊グラフィックスを指定できる。日本語コーデックが状態を所有する場合を除き、SI/SO で呼び出せる。DEC の罫線を対応する Unicode 罫線文字に変換する。文字集合の指定でプロファイルの通信エンコーディングを暗黙に変更しない。

## 表示属性、寸法、Unicode

SGR はリセット 0、太字 1、淡色 2、斜体 3、単一下線 4、反転 7、非表示 8、取り消し線 9、各リセット 22/23/24/27/28/29、30～37/40～47 と 90～97/100～107 に対応する。39/49 は固定の既定色に戻す。インデックス色と RGB の 38/48 はセミコロン形式と、色空間欄が省略または 0 のコロン形式に対応する。未対応の点滅、二重下線、色空間の形式は保存済みテキストを変更せず無視する。非表示属性は描画だけに影響し、秘密情報の除去には使わない。強調のスタイルは表示のみで、選択、検索、最初に一致したルール、端末の表示属性の順に優先する。

xterm 方式の 16 色パレットを次の順に使う。
`000000 CD0000 00CD00 CDCD00 0000EE CD00CD 00CDCD E5E5E5`
`7F7F7F FF0000 00FF00 FFFF00 5C5CFF FF00FF 00FFFF FFFFFF`。
インデックス 16～231 は 0/95/135/175/215/255 の 6 段階 RGB キューブ、232～255 はグレーの 8+10n。既定の白は FFFFFF でインデックス 7 とは独立する。RGB 値を保持する。選択は 0050A0 上の白、検索は FFD54F 上の黒で、現在の一致を白で囲む。カーソルは必要に応じて黒または白の対照的な塗りや枠と、反対色の文字を使う。フォーカスを失ったら枠にする。接続先による非表示指定が優先する。

分割と幅のデータを Unicode 17.0.0、UAX29 リビジョン 47、UAX11 リビジョン 44、Emoji 17/UTS51 リビジョン 29 に固定する。セル幅をフォントや OS に付属する Unicode データから決めない。初期描画は TabTty 独自の WPF コントロール、TextFormatter/DrawingContext、インストール済みフォントのフォールバックを使う。描画実装を変えてもセルの契約は保つ。Web レンダラーやサードパーティの端末コントロールは導入しない。

| ケース | セルと内容の規則 |
| --- | --- |
| 通常の Unicode クラスタ | 結合記号以外の基底スカラー値の最大幅。Wide/Fullwidth は 2、Ambiguous はプロファイルの 1/2、それ以外は 1。 |
| 認識済みの絵文字シーケンス | 対応する表示指定、ZWJ、修飾子のシーケンスを含めて 2 セル。テキスト異体字指定ではテキスト幅を使う。 |
| 結合、異体字、接合子による継続 | テキストを正規化せず直前の対象クラスタを拡張する。チャンク境界でクラスタを終了しない。 |
| 孤立した結合記号 | 1 セル。描画補助に点線の丸を使うが、保存、コピー、ログには含めない。 |
| 途中または繰り返しの U+FEFF | 幅ゼロの書式文字として内容、コピー、ログに保持する。Q126 の受信元ごとの先頭にある完全な UTF-8 シグネチャだけを消費する。 |
| 未認識の書記素や ZWJ シーケンス | スカラー値を保持して通常の基底文字の最大幅規則を使う。単一の合成グリフは保証しない。 |
| レガシー符号化からデコードしたテキスト | 厳密なマッピング後に同じ Unicode 幅を適用する。ロケールや OS による追加のバイト幅上書きは行わない。 |
| 最終列の幅広クラスタ | 折り返しありではクラスタ全体を次の行に移す。なしでは開始位置を左へ 1 列ずらし最後の 2 セルを確保する。クラスタの半分は保存しない。 |
| クラスタの一部にかかる編集や消去 | クラスタ全体に適用して空セルにする。孤立した継続セルや分割した Unicode 内容を残さない。 |

テキストを変える操作はリビジョンを進める。属性や配置だけの変更では進めない。逐次拡張されるクラスタの幅は変わり得るので、次のスナップショットを公開する前に配置を再計算する。最後に編集可能なクラスタの由来を保持する。上限を超える拡張は明示的な障害とし、暗黙に切り詰めない。再フローは通常画面でソフトラップした行だけを結合し、アンカー、属性、クラスタ、記録リビジョン、明示的なハード境界を保持する。公開前に取得済みの物理行数の上限を適用し、除去される対象 Text は LF なしで記録する。代替画面のサイズ変更は切り詰めと埋め合わせを行い、再フローしない。通常画面は復帰して再フローするまで退避する。

Consolas 12 pt、インストール済みのフォールバック、固定の行とセル寸法を使う。フォントがない場合は非致命的なフォールバック状態を表示する。必要なシェーピングを維持し、任意のプログラミング用合字を無効にする。列を広げず、グリフを割り当てたセルに収める。IME の合成はキャレットに固定した未確定オーバーレイとし、一度の確定までトランスポートとログには送らない。対応するキーイベントを消費し、別の Enter が送られないようにする。候補 UI はキャレット位置と DPI に追従する。タブの切り替え、切断、別の端末ペインへのフォーカス移動では、同じタブ内も含めて未確定の合成をキャンセルし、何も送らない。メニューやダイアログへのフォーカス変更は Windows の IME の挙動に従う。追加の確定やリモート入力は生成しない。Q184/Q195 に従い、各ペインは共有端末モデルに対してスクロール、選択、検索結果の移動が独立する。検索文字列と大文字小文字の区別、一時ズームはタブで共有する。[分割ビューの契約](broadcast-and-split-views-ja-jp.md)を参照。

UIA Text/TextRange に選択、キャレット、可視範囲、保持テキストを公開する。安定したコンテンツアンカーと通常の論理境界位置を使う。代替画面はその画面のアクティブな内容だけを公開する。除去された範囲は最も近い残存境界に縮退させる。古い範囲から解放済みバッファーを読まない。GetText(-1) は要求範囲全体を返し、非負の最大値では UIA の契約に従う。コピー前にスナップショットメモリを確保する。利用できない場合は明示的なプロバイダー障害を返し、暗黙の切り詰めや独自のページ分割は行わない。テキストイベントはまとめ、受信行すべてを既定でライブ読み上げせず、出力でフォーカスを変えない。

## キーボードとマウス

Tera Term 同梱の IBMKEYB.CNF を基準にする。通常の矢印は CSI A/B/C/D、アプリケーション矢印は SS3 A/B/C/D。Home/End は CSI 1~/4~。Insert/Delete/PgUp/PgDn は CSI 2~/3~/5~/6~。Shift+Tab は CSI Z。F1～F4 は SS3 P/Q/R/S、F5～F12 は CSI 15~/17~/18~/19~/20~/21~/23~/24~。数値キーパッドは通常文字を送る。アプリケーションキーパッドは数字 0～9 に SS3 p-q-r-s-t-u-v-w-x-y、小数点に n、Enter に M、乗算、加算、減算、除算に j/k/m/o。単独の Tab は HT、Escape は ESC。印字可能な入力は選んだ厳密な送信コーデックに従う。Ctrl と文字は通常の ASCII C0 に対応付ける。Alt と印字文字は ESC を前置する。AltGr と IME のテキストは印字文字のままとする。修飾付きの移動キーとファンクションキーは xterm CSI のパラメーター 1 + Shift(1)+Alt(2)+Ctrl(4) を使う。初期段階では modifyOtherKeys や拡張キーボードプロトコルを有効にしない。合意済みのローカルコマンドを優先する。

Enter/Backspace とローカルショートカットは Q88 と端末操作のドラフトのプロトコル既定値を保つ。SSH のエコーは Off に固定し、Telnet とシリアルの一時的な挙動は従来どおり。Ctrl+Shift+C/V はローカルのコピーと貼り付け。Ctrl+C/V は接続先への入力。右クリックはマウス報告がオフの場合か、Shift でローカル操作の所有を選んだ場合だけメニューを開く。それ以外は接続先へ報告する。メニューのズームに新しい Ctrl+ホイール割り当ては設けない。

マウスモード 9 は押下だけ、1000 は解放とホイールも、1002 はドラッグ中の移動も、1003 はすべてのセル移動も送る。最後に有効にした追跡モードが優先され、それを無効にすると追跡はオフになる。1006 は SGR 形式を選び、単独で追跡を有効にしない。従来の報告は CSI M に符号化したボタンと x/y を続け、1 始まりのセルを 223 に制限する。SGR は CSI <button;x;y M、解放は m。標準の Shift/Alt/Ctrl ビット 4/8/16、移動 32、ホイール 64/65 を加える。一つのセル内の移動はまとめる。操作開始時に合意済みの Shift によるローカル選択の上書きを適用して所有者を保持する。プロトコルモードまたは世代変更で接続先への操作をキャンセルし、新モードで旧モードの解放を作り出さない。ピクセル、urxvt、UTF-8 座標の拡張には対応しない。

同時送信の Q182/Q190 で座標処理を更新した。未対応またはグリッド外の押下と移動はスキップする。対応する解放は実際にボタンを離したときだけ範囲内に制限する。グリッドから出ても操作を終えない。[同時送信の契約](broadcast-and-split-views-ja-jp.md)ではプロトコル上限、キャプチャ、同じセッションのペイン座標も扱う。

## 文字コード変換の提供元

対応する文字コードは47種類。プロファイルの検証では未対応の文字コード識別子を拒否する。Windows/OEM コードページと KOI8-R には Win32 の厳密変換を使う。未定義の印字単位は U+FFFD に置き換える。CP932 の単独バイト A0、FD、FE、FF は未定義。送信時は変換したバイト列を復号すると元の Unicode に厳密に戻ることを確認する。

ISO-8859-10/11/14、EUC-JP、JIS は Windows 同梱 ICU を使う。EUC-JP では euc-jp-2007 に ASCII、SS2 の半角カナ、2バイト文字の変換を委ねる。形式上正しい SS3 単位は U+FFFD 一つとして扱う。

JIS は ICU の日本語 ISO-2022 変換器を使う。受信・送信それぞれの半角カナ設定に応じ、SO/SI にはバージョン3、8ビットにはバージョン4を選ぶ。Roman や漢字の切替、文字集合の選択、送信末尾の切替は ICU が行う。既存の漢字 IN/OUT の値はプロファイル内に保持し、接続時の指定には使わない。JIS の受信状態は入力元ごとにチャンクをまたいで保持し、VT 制御は端末パーサーに渡す。CP932 の SO/SI 受信設定では、呼び出されたカナを CP932 の変換器へ渡す。

レガシーのマルチバイトデコードでは、形式上正しい未定義または未対応の単位全体を消費し、U+FFFD を一つ生成する。不正な継続では保留中の先頭部分を一度だけ置換し、問題のバイトを新しい開始または制御として再処理する。EOF では保留中の文字の先頭部分を一度だけ置換する。チャンク末尾は EOF と区別する。EUC 8F A1 A1 は置換一つ、8F A1 0A は置換の後に LF。未完了の文字集合や VT の指定は不完全な制御として扱う。UTF-8 は最大部分列の置換を使う。E3 81 1B は置換の後に ESC、C0 AF は置換二つ。未定義の単バイト位置は置換一つ。送信単位はすべて厳密な事前検査を行い、拒否された入力は実エンコーダーの状態を変えない。自動エンコーディング検出や UTF-16 は導入しない。

## 検証と出典

承認後に制御の別名とリセット状態表、less/top/vim、全コーデックのチャンク分割、不正な入力から C0 への再同期、Roman の関連 4 文字の厳密な往復、拡張の重複、未対応文字集合、絵文字と結合文字と端の編集と再フロー、すべてのキーとマウスモード、IME の一度だけの確定、英語と日本語のナレーター操作を検証する。この時点で実行時の検証は未実施。

出典の事実と明示的な差異は `../drafts/technical-contract-review.md` に記録する。マッピングと分割の参考資料。[RFC 1468](https://www.rfc-editor.org/rfc/rfc1468.html)、[Microsoft の CP932 表](https://www.unicode.org/Public/MAPPINGS/VENDORS/MICSFT/WINDOWS/CP932.TXT)、[Microsoft EUC-JP](https://source.dot.net/System.Text.Encoding.CodePages/System/Text/EUCJPEncoding.cs.html)、[Unicode 17](https://www.unicode.org/versions/Unicode17.0.0/core-spec/chapter-3/)、[UAX29 rev47](https://www.unicode.org/reports/tr29/tr29-47.html)、[UAX11 rev44](https://www.unicode.org/reports/tr11/tr11-44.html)、[UTS51 rev29](https://www.unicode.org/reports/tr51/tr51-29.html)。セル幅の調整と内部上限は TabTty が定める。これらの標準がすべての端末セルの動作を定めるわけではない。
