# Complete native normal-screen editing and rendition

## What to build

Complete contracted normal-screen cursor movement, editing, scrolling regions, tabs, cursor save/restore, charset invocation, rendition, and source-local REP in the Rust terminal. Make their display and copy results observable through the active application path. Preserve existing recording regressions; complete native recording semantics belong to the later recording slices.

## Acceptance criteria

- [ ] Implement the contracted C0, ESC, CSI cursor/edit/scroll/tab operations, origin/insert/autowrap/LNM behavior, and distinct cursor-position versus full cursor saves. Preserve invalid-margin, erase, ED2, and ED3 behavior.
- [ ] Interpret complete private/parameter/intermediate/final spellings. Consume excluded well-framed controls, handle string terminators and cancellation, execute eligible embedded C0 once, and enforce parser limits and checked numeric arithmetic through shared Estimate/Execute rules.
- [ ] Preserve fixed terminal defaults, all contracted SGR forms and resets, true RGB, DEC graphics, and exact source-local REP. Excluded OSC controls cause no title, clipboard, hyperlink, or other external effects.
- [ ] Preserve Unicode 17 cluster rules, incremental width changes, interior FEFF, isolated marks, wide right-edge placement, and whole-cluster edit/erase. Cluster overflow is explicit failure rather than splitting or truncation.
- [ ] Verify representative complete operations through profile/session/render/copy and existing recording paths with independent expected output. Include malformed spelling, chunk/EOF, source interleaving, allocation rejection, and unchanged-content versus actual text revisions.
