# Record native alternate Text and canonical Terminal operations

## What to build

Produce alternate-screen Text and combined Terminal recordings in Rust across source, screen, interval, and EOF boundaries, delivering their complete bounded effects to the actual file-owning recording module.

## Acceptance criteria

- [ ] Record alternate printable text and TAB, preserve LF, resolve pending CR as contracted, and omit other nonprinting controls. Do not combine CR/LF across incompatible sources, intervals, or screen boundaries.
- [ ] Flush eligible normal tails once without LF on alternate entry, preserve parked normal provenance, and return without a normal-screen dump or recording restore-state prefix.
- [ ] Admit a completed received unit only when all source bytes belong to the current uninterrupted interval. Preserve incomplete-unit provenance and independent eligibility of an embedded executable C0 operation.
- [ ] Serialize Terminal output as UTF-8 text and canonical supported seven-bit controls with complete parameters, aliases normalized and REP resolved to source text. Include accepted local echo and display operations even when they do not change cells.
- [ ] Exclude queries/replies, BEL, excluded OSC effects, incomplete/unsupported fragments, resize, transport data, and diagnostics. Preserve source CR/LF and local echoed Enter as CRLF.
- [ ] Verify complete file bytes through the actual recording path for screen transitions, pause/resume inside units, source interleaving, EOF followed by cutoff, and recording admission refusal, without native state replacement.

## Blocked by

- T05 — Run alternate-screen applications with native input modes.
- T11 — Own complete native recording interval operations.
