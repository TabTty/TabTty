# Record edited native normal-screen Text across intervals

## What to build

Produce normal-screen Text files from the Rust receive-only projection, including edited revisions, logical boundaries, retirement, serialized TAB position, reflow, and interval eligibility.

## Acceptance criteria

- [ ] Exclude local echo and preserve source-local CRLF pairing across chunks. Only genuine received LF boundaries add log newline; cursor movement, wrapping, resize, erase, and local input do not manufacture one.
- [ ] Serialize surviving logical content and explicit spaces, join soft wraps, keep clusters whole, and emit TAB only when its final span matches ordinary eight-column expansion at the serialized position without hiding text.
- [ ] Mark exactly submitted content revisions and boundaries. Same-content rewrites do not create a revision; later actual edits append the updated surviving revision without rewriting old file regions.
- [ ] Before retention loss, emit eligible unrecorded spans without LF and later emit only remaining eligible continuation. Explicit erase/delete/overwrite/truncation does not take a pre-edit snapshot.
- [ ] Continue receive-only updates during pauses. On resume exclude retained mixed logical lines and their future continuation through the first received LF, with no backfill or duplicate tails.
- [ ] Verify complete old/new file bytes through actual recording operations across reflow, retirement, TAB edits, source interleaving, repeated finalization, and resource rejection, with serialized position owned inside the native module.

## Blocked by

- T06 — Resize native normal and parked terminal output.
- T11 — Own complete native recording interval operations.
