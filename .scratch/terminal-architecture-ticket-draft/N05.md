# Run alternate-screen applications with native input modes

## What to build

Support contracted alternate screens, resets, terminal replies, cursor presentation, and mode-dependent keyboard and mouse input in real native terminal sessions. Keep existing presentation, gesture ownership, broadcast coordination, and transport responsibilities with their current owners.

## Acceptance criteria

- [ ] Implement distinct 47, 1047, 1048, and 1049 behavior, including save/restore, clearing, and repeated set/reset idempotence. Keep parked normal content and its metadata intact.
- [ ] Implement DECSTR and RIS with their different reset scopes, primary DA, DSR and private/nonprivate CPR, and cursor visibility/style. Resets do not change profile settings, transport, logs, or application theme.
- [ ] Encode all contracted cursor, keypad, function, navigation, modifier, and mouse modes in Rust through the actual input path. Preserve bracketed-paste mode and exclude unsupported enhanced protocols.
- [ ] Preserve Shift gesture ownership, coordinate bounds, same-session pane coordinates, mode/generation cancellation, and existing broadcast skip/clamp rules without reimplementing BroadcastInput policy.
- [ ] Exercise representative full-screen applications and independent state/byte cases through the real application path, including replies during paste, mode transitions, repeated screen changes, and native admission failure.

## Blocked by

- T03 — Submit native UTF-8 input with committed local echo.
- T04 — Complete native normal-screen editing and rendition.
